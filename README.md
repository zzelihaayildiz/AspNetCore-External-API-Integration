# ASP.NET Core External API Integration

## Project Description

A simple ASP.NET Core MVC application that retrieves user data from an external REST API and displays it in a table.

## Technologies

* C#
* ASP.NET Core MVC
* .NET 8
* HttpClientFactory
* REST API
* JSON
* Razor Views

## Features

* Retrieve user data from JSONPlaceholder API.
* Send asynchronous HTTP GET requests.
* Deserialize JSON responses into C# models.
* Display user data using Razor Views.
* Manage API configuration through appsettings.json.
* Handle HTTP request exceptions.
* Handle null and empty responses.

## API

https://jsonplaceholder.typicode.com/users

## Architecture

* Models: User data model.
* Controllers: API requests and data handling.
* Views: Display user information.

## Purpose

This project was developed to practice external REST API integration with ASP.NET Core MVC.
